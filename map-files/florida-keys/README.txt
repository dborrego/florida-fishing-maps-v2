FloridaFishingMaps.com - Florida Keys GPS Fishing Maps

This package includes chartplotter-ready GPS fishing spots for the Florida Keys.

Included:
- FloridaFishingMaps-FL-Keys-SatView.kml
- FloridaFishingMaps-FL-Keys-NOAA.kmz
- FloridaFishingMaps-FL-Keys-Coordinates.csv
- GPS-Files/ for Garmin, Humminbird, Lowrance, Raymarine, and Simrad
- INSTRUCTIONS.txt
- GPS-SD-CARD-INSTRUCTIONS.txt
- Guides/ with fishing, rigging, seasonal, and safety guidance

Start with INSTRUCTIONS.txt. Back up your existing chartplotter waypoints before importing.

Use all coordinates for fishing and trip planning only. Never use fishing waypoints as navigation routes.
